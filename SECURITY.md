# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

As an open-source utility platform, security, input sanitization, and numerical precision are paramount.

If you find a security vulnerability:
1. Please do not open a public issue.
2. Email **Musfiqur Rahman Saimon** at `saimon@ascentraconsulting.co.uk` with the details and reproduction steps.
3. Reports are reviewed and addressed promptly.
